# Codex 任务书：PluckApp v0.1 菜单栏 GUI 人工验证（computer use）

你将用 computer use 驱动 macOS GUI，验证 Pluck 菜单栏 app 的 8 项交互。仓库在 `/Users/ruochen/workspace/pluck`，测试图片在 `Tests/Fixtures/`。

**总规则**：

- 每个用例截图留证，存到 `/tmp/pluck-qa/`（先 `mkdir -p`）。
- 结果写到 `/tmp/pluck-qa/report.md`：表格列 用例 ID / 预期 / 实际 / PASS 或 FAIL / 截图文件名。FAIL 的用例额外记录复现步骤和现象细节。
- **不要碰 git**，不要改仓库内任何文件。
- 遇到 app 崩溃：保存崩溃信息（`log show --last 2m --predicate 'process == "PluckApp"'`），标 FAIL，继续后面能做的用例。

## 准备

```bash
cd /Users/ruochen/workspace/pluck
pkill -f PluckApp || true
mkdir -p /tmp/pluck-qa
swift run PluckApp > /tmp/pluck-qa/app.log 2>&1 &
sleep 5
```

确认菜单栏右侧出现一个小图标（实心不规则圆形，下方有虚线轮廓）。截图整条菜单栏 → `00-launch.png`。

## 用例

**T1 · popover ⌘V 剪贴板闭环（最重要）**
用 Preview 打开 `Tests/Fixtures/hair-01.jpg`，⌘A 全选、⌘C 复制。单击菜单栏图标打开 popover，在 popover 里按 ⌘V。预期：菜单栏图标短暂（约 0.5s）出现成功反馈（变实心/绿色调），无任何弹窗，且 Recent 网格多出一项。然后 Preview 菜单 File → New from Clipboard。预期：新图是抠好的人像、背景透明——即结果已自动写回剪贴板。截图 → `01-paste-result.png`。关闭不保存。

**T2 · 剪贴板无图的失败反馈**
先在任意文本框复制一段文字（让剪贴板里只有文本），打开 popover 按 ⌘V。预期：图标短暂显示失败态（红色调），**不弹任何对话框**。截图抓反馈瞬间（可多按几次配合连拍）→ `02-paste-fail.png`。

**T3 · 无主体图片的失败反馈**
Preview 打开 `Tests/Fixtures/nosubject-01.jpg`，⌘A ⌘C，popover 内 ⌘V。预期：同 T2 的失败态，无弹窗。→ `03-nosubject.png`。

**T4 · 拖文件到菜单栏图标**
打开 Finder 窗口定位到 `Tests/Fixtures/`，把 `product-01.jpg` **拖到菜单栏的 Pluck 图标上**松手。预期：拖入悬停时图标有高亮反馈；松手后进入处理（图标变暗），完成后成功反馈。→ `04-drop-on-icon.png`。

**T5 · Popover 打开与布局**
单击菜单栏图标。预期：弹出 popover（约 340×440），从上到下：一条细提示行（≤44pt，文案 "Drop or paste images here"）、"Recent" 标题 + 网格（此时应有 T1/T4 的两个结果，棋盘格底缩略图）、底部左 Quit 右齿轮。**重点验证：点击能打开 popover**（实现上图标被拖放覆盖层遮挡，点击转发是已知风险点）。另外把一个文件从 Finder 拖到 popover **中部（Recent 区域）** 而非顶部提示行：预期整块 popover 高亮并接受拖放。截图 → `05-popover.png`、`05b-drop-highlight.png`。

**T6 · Recent 网格：hover 按钮 + Copy**
鼠标悬停在一个 Recent 缩略图上。预期：出现 Copy / Save 两个小按钮。点 Copy，然后 Preview → File → New from Clipboard 验证是透明底抠图。→ `06-recent-hover.png`、`06b-copy-verify.png`。

**T7 · Recent 缩略图拖出**
从 popover 的 Recent 网格里把一个缩略图**拖到桌面**（或 Finder 窗口）。预期：落地生成一个 .png 文件，文件名合理（非乱码），打开验证透明底。→ `07-dragout.png`。

**T8 · 深色模式图标可辨性**
执行：
```bash
osascript -e 'tell app "System Events" to tell appearance preferences to set dark mode to true'
```
截图菜单栏（放大到能看清图标细节）→ `08-dark-icon.png`。再切回：
```bash
osascript -e 'tell app "System Events" to tell appearance preferences to set dark mode to false'
```
截图 → `08b-light-icon.png`。两种模式下图标都应清晰可辨（template 渲染，深色下应自动变白）。记录你对 18pt 下"实心 blob + 虚线"是否可辨的主观判断。

**T9 · Save 按钮与 ⌘Q**
popover 里对一个 Recent 项点 Save。预期：弹出系统存储面板（app 是 accessory 模式，验证面板能正常获得焦点）；存到 `/tmp/pluck-qa/saved.png`，验证文件存在。最后在 popover 打开状态下按 ⌘Q。预期：app 退出，`pgrep -f PluckApp` 无结果。→ `09-save.png`。

**T10 · Recent 预览面板（before/after 滑块）**
单击一个 Recent 缩略图。预期：弹出约 480×420 的面板，标题是该图名；面板中部左侧原图、右侧棋盘格上的抠图结果，中间一条白色竖线带圆形手柄。左右拖动手柄，分界线跟随、两侧图像严格对齐（不应有位移或缩放差）。点底部 Copy 验证剪贴板，点 Save 验证存盘。按 Esc 关闭。再点另一个缩略图：预期复用同一面板换内容，**不叠出第二个窗口**。→ `10-preview.png`、`10b-slider-dragged.png`。
