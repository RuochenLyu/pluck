Pluck 是一个小巧的原生 Mac 抠图应用。照片不出电脑，抠图就地完成。 不用注册，不用上传，更不用每周交钱。

三个引擎

同一张图，不止一个答案

大多数工具只给你一个模型。Pluck 装了三个——因为"主体到底是什么"， 不同的图有不同的答案，有时候连你自己想要哪个答案，都得看过才知道。

一张翻拍的画

Apple Vision 认为主体是这幅带框的画，把它整个取下来； 利落边却看进了画里，只把猫抠了出来。拖动对比这两个答案。

Vision 利落边

一杯红酒

柔细边保留了真实的透明度——棋盘格从玻璃杯里透出来， 因为玻璃本来就是透明的。这里只有它做得到。

原图 柔细边

为什么选 Pluck

小而美，而且不装

没有上传，就没有泄露

抠图在你 Mac 自己的芯片上完成——Apple Vision 框架，或本地 Core ML 模型。 应用里没有账号，也压根没有上传这条路。

三个引擎，三种判断

Vision 秒出结果，没有主体时会诚实说没有；利落边擅长硬边和线稿； 柔细边连发丝都留得住。逐张切换，实时对比。

是 Mac 应用，不是套壳网页

拖进来，或者直接 ⌘V。一个窗口：网格或列表看结果，旁边就是前后对比， 好了就导出。它和你其他窗口一个做派，因为它就是照那样造的。

你的 AI agent 也能开

同一个引擎以 pluck 命令行发布——JSON 输出、诚实的 exit code、 绝不弹窗。Claude 或任何编程 agent 一行命令批量处理一个文件夹。

大模型，你要才下

高质量引擎是一次 83 MB 的按需下载，校验和钉死在签名的应用里。 更新检查只比对本地文件——零网络请求。

免费就是免费

没有水印，没有"高清版每周 ¥68"，没有试用倒计时。 MIT 协议——代码随便读，自己编译，永远是你的。

模型下载

仅当你点击下载或运行 pluck models pull 时发生。从本仓库的 GitHub Releases 拉取，并对照签名应用内钉死的校验和验证。

怎么关 你不要求，它就不会发生。

更新检查

应用每天问一次 GitHub 有没有新版本。关于你和你照片的任何信息， 都不会跟着一起去。

怎么关 设置 → 通用。关掉就是彻底安静。

终端与 agent

同一个引擎，一条命令的距离

结构化输出、语义化 exit code、永不弹 GUI。自己写脚本， 或把内置的 agent skill 交给 Claude。

pluck photo.jpg                        # → photo.png，背景没了
pluck shots/*.jpg -o cutouts/ --json   # 一次一个文件夹，NDJSON 输出
pluck photo.jpg --model birefnet-lite-matting
pluck models list                      # 这台机器能跑什么
