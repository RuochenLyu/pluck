Pluck 是一个小巧的原生 Mac 抠图应用。照片不出电脑，抠图就地完成。 不用注册，不用上传，更不用每周交钱。

三个引擎

同一张图，不止一个答案

大多数工具只给你一个模型。Pluck 装了三个——因为"主体到底是什么"， 不同的图有不同的答案，有时候连你自己想要哪个答案，都得看过才知道。

一张翻拍的画

Apple Vision 认为主体是这幅带框的画，把它整个取下来； 利落边却看进了画里，只把猫抠了出来。拖动对比这两个答案。

⇄
Vision 利落边

一杯红酒

柔细边保留了真实的透明度——玻璃后面能看到棋盘格， 因为玻璃本来就是透的。这一手，另外两个引擎都做不到。

🔒

不联网，才谈得上隐私

抠图跑在 Mac 自己的芯片上——系统的 Vision 框架，或本地 Core ML 模型。 应用里没有账号，也压根没有上传这条路。

🪄

三个引擎，各有脾气

Vision 秒出结果，图里没主体它会直说；利落边擅长硬朗的边缘和线稿； 柔细边能留住每一根发丝。一张图不满意，换个引擎马上再看。

🖥️

是 Mac 应用，不是套壳网页

拖进来，或者直接 ⌘V。一个窗口：网格或列表看图，旁边就是前后对比， 看完一键导出。举止和你的其他窗口一样，因为它就是原生的。

🤖

你的 AI 也会用

同一个引擎做成了 pluck 命令行：JSON 输出、规矩的退出码、 永不弹窗。让 Claude 或任何 agent 一行命令处理整个文件夹。

📦

大模型，想要才下

高精度引擎是一个 83 MB 的可选下载，哈希校验后才落盘。 检查模型更新走本地比对，一个网络请求都不发。

💛

免费就是免费

没有水印，没有"高清版 9.9 一周"，没有试用倒计时。 MIT 开源——代码随便看，自己编译也行，永远是你的。

隐私

会联网的事，一共两件

隐私承诺值多少钱，全看例外交代得清不清楚。Pluck 的例外全在这里：

哪件事什么时候怎么关
下载模型 只在你点了下载、或运行 pluck models pull 的时候。 下载的文件要对上签名应用里钉死的校验值才会安装。 你不点，它不动。
检查更新 应用每天问一次 GitHub 有没有新版本。关于你和你照片的信息，一个字节都不捎带。 设置 → 通用。关掉后就再没有任何主动请求。

终端与 agent

同一个引擎，一行命令

结构化输出、有含义的退出码、永不弹 GUI。自己写脚本可以， 把内置的 agent skill 丢给 Claude 也可以。

pluck photo.jpg                        # → photo.png，背景没了
pluck shots/*.jpg -o cutouts/ --json   # 一次一个文件夹，NDJSON 输出
pluck photo.jpg --model birefnet-lite-matting
pluck models list                      # 这台机器能跑哪些引擎
